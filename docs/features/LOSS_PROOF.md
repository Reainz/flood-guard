# Loss Proof Documentation System

## Purpose

Help farmers document crop losses with GPS-tagged photos and generate
a government-formatted evidence package to support compensation claims
under Nghị định 02/2017/NĐ-CP.

## Why this feature exists

Under ND 02/2017, farmers must submit documented evidence of loss to
provincial DARD (Department of Agriculture and Rural Development) offices
within 15 days of a disaster declaration. Most farmers either:
1. Don't claim because they don't know the process
2. Lose claims because their evidence is insufficient

FloodGuard automates the evidence collection so any farmer with a
smartphone can generate a valid submission package.

## Photo requirements

| Photo type | Required | Notes |
|-----------|----------|-------|
| Before flood — full field | ✅ | Shows pre-flood crop condition |
| After flood — full field | ✅ | Shows damage extent |
| Crop close-up | Recommended | Shows grain/plant damage detail |
| Water depth indicator | Recommended | Person/stick in flood water |

Minimum 2 photos, recommended 4+. Each photo must have:
- GPS coordinates (from device location at time of photo)
- Timestamp (device clock, stored in EXIF + our metadata)
- Cannot be edited after upload (hash stored for integrity)

Evidence completeness score:
- 2 photos = 50% photo score
- 4 photos = 100% photo score
- Field form complete = +32%
- Total max = 100%

Higher completeness → higher claim approval rate (documented in DARD guidelines).

## Compensation calculation

Source: Nghị định 02/2017/NĐ-CP, Phụ lục I

```
compensation_vnd = area_ha × rate_vnd_per_ha × (loss_pct / 100)
```

But rate_vnd_per_ha is tiered by loss severity:
- loss < 30%: NOT eligible (0 VND)
- loss 30–70%: lower rate
- loss > 70%: higher rate (see `docs/features/HARVEST_ENGINE.md` for rates)

The full rate table is in `backend/proof/compensation.py`.
Never modify it without citing an update to ND 02/2017 or its amendments.

## Evidence package output

The system generates a PDF containing:
1. Cover page: farmer name, field ID, report ID, submission date
2. Field details: crop type, area, location (GPS coordinates as map)
3. Damage assessment: loss %, flood duration, depth
4. Photo gallery: all submitted photos with GPS + timestamp overlay
5. Compensation estimate: calculated amount, legal basis
6. Checklist: additional documents farmer must submit to DARD

PDF is generated by `backend/proof/pdf_generator.py` using `reportlab`.

## Report ID format

```
FG-{province_code}-{field_id}-{YYYYMMDDHHMMSS}
```

Example: `FG-AG-TCPU-2024-00847-20260502143022`
- `FG` = FloodGuard
- `AG` = An Giang province
- `TCPU-2024-00847` = farmer's land registration number
- `20260502143022` = UTC timestamp of submission

## Privacy rules

- GPS coordinates are stored ONLY in the evidence package PDF
- GPS coordinates are NEVER logged to application logs
- Farmer name and field ID are NEVER logged
- Evidence photos are stored in `/uploads/{report_id}/` and served only
  to the authenticated farmer session (no public URLs)
- Data retention: evidence packages kept for 90 days, then deleted
  unless farmer explicitly requests extension
